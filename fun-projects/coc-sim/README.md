# TH8 War Sim

A tick-by-tick Clash of Clans battle simulator for **max Town Hall 8** (home village / war
base). It finds what actually works by:

- simulating real meta attacks (GoWiPe, GoHo, GoVaHo, Mass Dragons, DragLoon, Mass Hogs,
  Balloon+Minion, GiWi) as deployment plans with reactive spells and hero abilities
- tuning each attack: hero (one slot at TH8), equipment, deploy width ("spreading"),
  timing, army swaps, which Air Defense to zap, and the best side per base
- evolving war bases with a genetic algorithm against the tuned attacks
- repeating both in an arms race and writing a report: `docs/RESULTS.md`

Stats come from game data at TH8 caps. Mechanics the data doesn't cover are documented
with confidence levels and can be **calibrated against real replays**.

## Quick start

Needs Node 22.18+ (runs TypeScript directly, no build step).

```bash
npm install
npm test                       # mechanics regression tests
npm run web                    # builds web/dist/index.html: open it in a browser
npm run sim -- matrix          # every strategy vs every base
npm run study                  # full arms race → docs/RESULTS.md (~15-40 min on 4 cores)
```

## The web app

`web/dist/index.html` is self-contained (engine + data inlined). It has:

- **Run attack**: picks base, strategy, hero, direction, spread and "sloppiness" (human
  deploy imprecision), then plays the replay on the board with shots, spells, HP bars and
  defending CC/hero units (red rings)
- **Test 24 variations**: 8 directions × 3 seeds, giving the 3★ / 2★+ rates on that base
- **Base editor**: place every TH8 building, wall and trap, with count limits and validation; JSON import/export
- the bases and tuned attack setups from the last `npm run study` are baked in

## CLI

```bash
npm run sim -- attack --strategy goho --base best-1 --angle 90 --hero archer-queen --log
npm run sim -- matrix --angles 8 --seeds 2 [--bases best-1,ring-core]
npm run sim -- opt-attack --strategy mass-dragon --iters 20
npm run sim -- opt-base --pop 24 --gens 15 --name my-base
npm run sim -- study --rounds 3 --pop 24 --gens 14 --iters 12
npm run sim -- validate bases/my-base.json
npm run sim -- mechanics                     # every mechanics knob + confidence
npm run sim -- calibrate --file calibration/replays.json [--fit]
COC_API_TOKEN=... npm run sim -- player --tag '#YOURTAG'      # your levels vs TH8 max
COC_API_TOKEN=... npm run sim -- warstats --clan '#CLANTAG'   # real TH8 vs TH8 star rates
```

## How realistic is it?

Simulated tick by tick (0.1 s):

- targeting with preferred targets, retarget pauses and aggro on defending troops
- ground pathfinding where walls cost path length and troops break them when that's cheaper
- Hog wall-jumping, flying units, Air Sweeper pushback
- every TH8 defense: Mortar blind spot and shell flight time, Hidden Tesla reveal, Bomb
  Tower death damage, Wizard Tower splash on ground and air
- every TH8 trap: Giant Bomb, Spring capacity, Seeking Air Mine, Air Bomb, Skeleton Trap
- Lightning, Heal, Rage, Poison and Earthquake (diminishing returns), plus CC spells (Freeze etc.)
- defending CC troops at donor levels, the defending hero, both heroes' equipment
- 3-minute timer, stars and destruction % by building count

Known gaps: exact hitbox sizes, exact wall-pathing weights, some epic-equipment summons, and
deploy-animation delays are estimates. `docs/RESEARCH.md` lists every source and confidence
level, and `docs/CALIBRATION.md` explains how to fix the estimates with real attacks. Treat
results as **rankings** (A beats B) until calibrated, not exact percentages.

## Layout

```
data/th8.json          TH8-max stats (generated by tools/extract-th8.ts)
src/engine/            sim.ts (battle loop), pathing.ts, mechanics.ts (curated rules), data.ts
src/strategies/        meta.ts (attack plans), common.ts (scripting + reactive spells), replay.ts
src/bases/             layout format + validation, generator.ts (wall templates + genome)
src/optimize/          worker pool, attack hill-climber, base GA
src/study.ts           arms race + report
src/api/coc.ts         official Clash of Clans API client
web/                   browser app (editor + replay viewer)
bases/                 saved layouts (archetypes + evolved bases)
calibration/           real-replay files and fitted knobs
docs/                  RESULTS.md, RESEARCH.md, CALIBRATION.md
```
